# Математика рядом — 3 класс

Статическое приложение на русском языке: 17 тем, генерация вариантов, подсказки в три шага, наглядные группы предметов, таблица умножения 1–10, тренировка умножения и деления, повторение ошибок, статистика самостоятельных решений и решений с помощью. Без сервера, регистрации и сторонних библиотек.

## Запуск по ссылке

В репозитории откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**. Запустите workflow **Check and deploy GitHub Pages**, если он ещё не завершился успешно. После публикации адрес: https://ratamahata8.github.io/math_pro/ .

## Локально

`npm start`, затем http://localhost:8000. Проверка математического генератора: `npm test` (Node.js 22+). Установка зависимостей не нужна.

## Содержание и ограничения

Основа тем — [федеральная рабочая программа математики 1–4 классов, 2025](https://edsoo.ru/wp-content/uploads/2025/07/2025_noo_frp_matematika_1-4.pdf), раздел 3 класса. Задания авторские, страницы учебников не копируются. Не заявляется полное соответствие всем учебникам или всем изменениям программы 2026 года. В первой версии ещё нет интерактивного деления уголком, полного алгоритма вычислений в столбик, построений фигур и отдельного тренажёра диаграмм. Проверять охват следует по конкретному учебнику ребёнка.

Данные хранятся в localStorage текущего браузера; очистка данных сайта удалит прогресс. Нет синхронизации устройств и профилей нескольких детей. Первую версию следует просмотреть взрослому перед самостоятельным использованием ребёнком.

## Структура

- `src/content.js` — темы, генераторы, объяснения, проверка ответа.
- `src/app.js` — интерфейс, сессии, повторение ошибок, локальная статистика.
- `src/style.css` — адаптивный интерфейс.
- `tests/content.test.js` — инварианты генерации и проверки.
- `.github/workflows/pages.yml` — тесты и публикация.
